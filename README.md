# GST Billing Software

Backend-focused billing system for GST invoice and inventory management.

## Features
- JWT Authentication
- Invoice Management
- Inventory Tracking
- Payment Tracking
- WhatsApp Notifications

## Tech Stack
- Node.js
- Express.js
- MongoDB
